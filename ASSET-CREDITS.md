# 3D Asset Credits and License Checklist

The project owner supplied character, vehicle, enemy, weapon, architecture, tunnel, traffic, and aerial model packages during development.

Runtime filenames were changed to original Aether Grid terminology for project organization. Renaming a file does **not** change the copyright or license of its underlying model.

Before publishing the repository, playable demo, trailer, screenshots, or a commercial build, verify for every third-party asset:

- Original creator and source page
- Ownership or valid license
- Redistribution permission
- Modification permission
- Commercial-use permission
- Required attribution
- Restrictions on derivative works

The lean player build contains browser-ready GLB assets only. Original FBX, Maya, Blender, USDZ, ZIP, and RAR packages remain in the separate developer archive and must not be deployed publicly unless their licenses allow redistribution.

Runtime proxies, normalization, material tuning, LOD decisions, and integration code are Sammium Tech development work, but the original visual subjects and textures may still be governed by third-party licenses.
