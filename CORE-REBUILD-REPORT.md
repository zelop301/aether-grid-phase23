# Aether Grid Core Rebuild Report

## Rebuilt now

- One campaign-first main menu instead of a development-phase dashboard
- Genesis Breach promoted as the official new-game experience
- Real byte-based critical asset loading progress
- Automatic first-launch graphics recommendation
- Optional in-game performance benchmark
- Compact HUD as the default presentation
- Development phase labels removed from normal gameplay
- Enemy and vehicle terminology moved toward an original Aether Grid identity
- Centralized runtime asset registry
- Runtime models renamed to original project terminology
- Public FBX/source archives removed from the player build
- Validated checkpoints, Continue, recovery, difficulty, driving assistance, controller support, accessibility, Photo Mode, and autopilot preserved
- Production runtime kept below the 55 MB public budget

## Preserved from the prototype

- Signal Fracture story and branching ending
- Returning Vector Disc combat
- Five differentiated Warden roles
- Attack-token coordination
- Flux Cycle racing and extraction
- Autopilot loop
- Hacking, checkpoints, adaptive quality, procedural audio, and Photo Mode

## External production tasks still required

These cannot be completed correctly by code-only patching:

1. Rig and weight-paint the final hero in Blender.
2. Retarget authored locomotion, combat, damage, finisher, mount, and riding animation clips to one skeleton.
3. Verify licenses and redistribution rights for every supplied third-party model.
4. Create simplified LOD meshes and dedicated collision meshes in a 3D authoring tool.
5. Replace strongly franchise-recognizable models with original silhouettes before a commercial release.

The runtime auto-rig remains a functional fallback, not the intended final character pipeline.
